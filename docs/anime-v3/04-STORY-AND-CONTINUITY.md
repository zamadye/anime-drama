# Story & continuity
Status: workflow specified; example series is draft.

## Portable writing workflow
Any agent/model may write, but deliver local versioned data and human-readable script. No LLM call in a React render. Keep source script, compiled timing and published canon distinct.

Bible → season outline → episode beats → script → continuity audit → storyboard → user review → audio and production. After review, store the reviewed revision and fingerprint. Content changes invalidate that review. Never set approved status on behalf of the user.

## Series bible
ID/revision, premise, genre/tone/audience, language, world rules, character IDs and immutable identities, relationships, goals/flaws/voice, locations, timeline, open conflicts and unanswered promises. Distinguish verified facts, proposals and contradictions.

## Scene and dialogue
Each scene specifies place/time, participants, objective, obstacle, stakes, entry emotion, turning point, exit state and consequence. Dialogue has stable line ID, speaker, words, subtext and delivery. Stage actions include who moves, where, what they touch and why. No filler to reach duration.

Draft target 10 minutes; allowed 8–12. Audio + actions determine final timing, not guessed words-per-minute alone. Preserve natural pauses. Rework script when outside target rather than stretching video.

## Continuity ledger
Track event ID, source episode/scene, world time, changed facts, who witnessed/learned them, relationship changes, prop/costume state and unresolved consequences. Character knowledge is separate from world truth. Proposal → script-approved → published canon are distinct states; a retcon requires an explicit recorded decision.

## Example
Senja uses existing four identities. E01 explores Kirana leaving and Arga's reluctance to speak; source pilot dialogue is inspiration, not an immutable ten-minute script. A six-episode proposed arc lives under content/series/senja. A second unrelated series must load without changing renderer code as a future portability acceptance test.

## Authoring review
Check causality, distinct voices, repetition, emotional turns and credible knowledge. List contradictions with evidence, not just a score. Preserve conflict between episodes while giving each episode a local consequence. User reviews actual script + shot storyboard, not a vague outline.
